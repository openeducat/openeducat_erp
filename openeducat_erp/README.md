# openeducat_erp – openEMIS ERP Meta-Module 🔗

## Overview

`openeducat_erp` is a **meta-module** (bundle) that declares all openEMIS modules as dependencies, allowing a single-click install of the complete suite.

Installing this module automatically installs:

| Module | Purpose |
|--------|---------|
| `openeducat_core` | Students, courses, subjects, faculty |
| `openeducat_admission` | Admissions workflow |
| `openeducat_assignment` | Assignment management |
| `openeducat_attendance` | Attendance tracking |
| `openeducat_classroom` | Classroom register |
| `openeducat_exam` | Examination management |
| `openeducat_fees` | Fee & finance management |
| `openeducat_library` | Library with CBC categorisation |
| `openeducat_timetable` | Timetable scheduling |
| `openeducat_parent` | Parent portal |
| `openeducat_facility` | Facility management |
| `openeducat_activity` | Extra-curricular activities |
| `openeducat_digiguide` | DigiGuide – digital career guidance |
| `openeducat_mentorship` | Mentorship platform |
| `openeducat_blog` | Educational blog |

---

## Installation

1. Place all openEMIS modules in your Odoo addons directory.
2. Update the app list in Odoo.
3. Search for **openEMIS ERP** and click **Install**.
4. Optionally enable **Load Demo Data** to populate sample records.
